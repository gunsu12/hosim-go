# ICD-10

Dokumentasi ini ditujukan bagi kontributor (developer dan AI agent) agar memahami konteks bisnis, integritas data, dan aturan operasional entitas `ICD-10` di HOSIM-GO.

## Business Context

ICD-10 adalah sistem klasifikasi diagnosis medis yang digunakan menggantikan ICD-9-CM. Sistem ini digunakan untuk mengklasifikasikan penyakit, cedera, dan kondisi medis lainnya. ICD-10 digunakan untuk tujuan penagihan, statistik, dan epidemiologi.
